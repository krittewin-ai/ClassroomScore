ตั้งค่าครั้งเดียว แล้วเปิดที่เครื่องไหนก็เห็นข้อมูลเดียวกัน

วิธีตั้งค่าแบบฟรี (Firebase — ใช้เวลา ~3 นาที)
คำเตือน: test mode เหมาะสำหรับทดสอบเท่านั้น ควรตั้ง Firebase Authentication + Database Rules ก่อนใช้งานจริง
  1. เข้า console.firebase.google.com → สร้างโปรเจกต์
  2. เมนู Build → Realtime Database → Create Database (เลือก test mode เฉพาะตอนทดลอง)
  3. คัดลอก URL ที่ขึ้นต้นด้วย https://xxxx.firebaseio.com หรือ ...firebasedatabase.app
  4. วาง URL ด้านล่าง → กด ทดสอบการเชื่อมต่อ → อัปโหลด (ข้อมูลจะอยู่ที่ /scoreapp/{รหัสห้อง})
  5. ที่เครื่องอื่น เปิดไฟล์เดียวกัน ใส่ URL + รหัสห้องข้อมูล ให้ตรงกัน แล้วกด ดึงข้อมูล
ซิงก์อัตโนมัติอัปโหลดเองหลังแก้ไข และดึงข้อมูลเมื่อเปิดเว็บ
